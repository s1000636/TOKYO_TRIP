# TOKYO TRIP 2.0

這是一個 GitHub Pages / PWA 版東京 6天5夜旅行 App。

## 部署
1. 將本資料夾內所有檔案上傳到 GitHub repository `TOKYO_TRIP` 的根目錄。
2. GitHub → Settings → Pages。
3. Source 選 `Deploy from a branch`。
4. Branch 選 `main`、資料夾選 `/ (root)`，儲存。
5. 等待部署後，用 `https://你的帳號.github.io/TOKYO_TRIP/` 開啟。

## 已包含
- 10/6–10/11 六天行程
- Day 2 小網神社、上野動物園、阿美橫町、淺草
- Day 3 東京迪士尼海洋
- Day 4 Pixar 東京站、豐洲、台場
- Day 5 明治神宮、原宿、表參道、澀谷、SHIBUYA SKY、新宿
- Day 6 錦糸町、成田、16:20 回程
- 行程時間軸、Google Maps 導航、記帳、日幣/台幣換算、行李清單、PWA/離線快取

## 注意
即時天氣、即時電車班次、票券與預約資訊沒有硬寫死，旅途中請以官方資訊與 Google Maps 當日結果為準。
